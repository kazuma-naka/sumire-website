FEATURES

What you can do with Sumire

Combine input methods, conversion, dictionaries, and display options to fit the way you type. Some features depend on your settings or the text field in use.

01

INPUT MODES

Choose an input method

12-key kana input

Type kana with a phone-friendly 12-key layout. Adjust flick or multi-tap input, repeat delay, sensitivity, and flick hit areas. Choose Japanese, English, or number modes and configure key guides.

Gojūon layout

Enter characters from a keyboard arranged by the Japanese gojūon syllabary.

Sumire layout

Use Sumire's original kana layout. Adjust key arrangement, input style, flick origin, key guides, and special keys. Optional actions include donut input, three-row flick, and Circular Flick.

QWERTY English input

Type English on a QWERTY layout. The beta glide input shows English word candidates from a finger path across the keys. Configure number keys, punctuation, cursor, emoji, and popups.

QWERTY romaji input

Type Japanese with romaji on a QWERTY layout. The romaji conversion table can be customized.

Custom keyboard

Select a custom layout stored on the device and adjust key size, tap and flick output, guides, and how multi-character input is committed.

Floating and split layouts

Float the keyboard and change its position or size. Configure tablet layouts and landscape behavior. Available layouts depend on the device and screen.

Physical keyboard

Options are available for typing and shortcut behavior with a connected physical keyboard.

02

CONVERSION

Convert while you review suggestions

Prediction and phrase editing

Show Japanese and English predictions and conversion candidates. Configure beta live conversion, inline candidates, and follow-up suggestions after committing text. Adjust candidate-row height, columns, and tabs. Choose how to split or move between phrase segments and restore a reading.

Typing correction

Set up correction for Japanese flick and English QWERTY input, as well as typing that omits modifier keys. Control candidate order and sources, including N-gram, the system dictionary, and external Mozc dictionaries.

Calculations and unit conversion

Enter an expression and use its calculated result as a candidate. Expression results appear after regular candidates and are never committed automatically. Set angle units and calculation precision. Unit conversion covers length, area, volume, mass, temperature, speed, pressure, energy, power, time, and data.

03

DICTIONARIES & TOOLS

Use dictionaries and tools

User and learning dictionaries

Add words and readings for conversion and prediction. Choose what the learning dictionary records and whether learned candidates appear, including in secret mode.

External dictionaries and blocked words

Use external files, the system user dictionary, system dictionary, and Mozc dictionaries as candidate sources. Manage words hidden from suggestions and labels for dictionary candidates.

Text snippets and macros

Save frequently used text for quick entry. Dynamic snippets can also appear in readings and candidate lists.

Emoji, symbols, and kaomoji

Pick emoji, symbols, and Japanese text faces from dedicated keyboards. Options control their display and suggestions.

Clipboard

Open clipboard history and configure its candidates, tap-to-delete, pins, and automatic removal of unpinned entries. Customize the shortcut toolbar or combine it with the candidate row.

Backup

Back up and restore settings. Follow the in-app prompts before using these actions.

04

EDITING

Edit and manage text

Move the cursor and undo

Move the cursor by long-pressing the space key and undo input. Choose whether to show cursor buttons.

Delete-key actions

Assign actions to left, right, or upward flicks on the delete key. Choose which symbols to delete and how long-press conversion works.

Adapt to the text field

Set suggestions for password fields and behavior when an app does not specify an input type. Configure full-screen landscape input and cursor movement after committing paired symbols.

05

PERSONALIZATION

Adjust appearance and behavior

Themes and key display

Choose a keyboard theme and use an image or video as its background. Adjust background fitting, video quality, key labels, candidate row, floating view, position, size, and corner radius.

Touch, vibration, and sound

Adjust touch effects, including color, strength, response, rendering quality, and motion. Configure key vibration, sounds, volume, and long-press delay.

Input languages and layouts

Configure input languages, keyboard layouts, and the contents of secondary keyboards.

Voice input

Open speech recognition available on the device. Service support and network requirements vary by device and recognition provider.

06

FULL EDITION AI

zenz and Gemma in Full

zenz AI conversion

Configure AI predictions, typing correction, and conversion candidate order. Adjust profiles, context, inference delay, and limits.

Gemma translation and actions

Select a supported model installed on the device, choose translation targets and a backend, and create Gemma actions with instructions for text, images, and audio. Check the app settings for supported model details.

Handwriting keyboard

Write on screen to recognize characters. Adjust recognition delay, pen width and color, recognition languages, and extra hints.

Full-only features

zenz, Gemma translation and actions, and the handwriting keyboard are for Full and are not included in Lite. Availability depends on the device, settings, app version, and required models.
